Thêm các nút liên hệ (Gọi, Zalo, Messenger, Lên đầu trang) cố định vào website WordPress. Kết nối tức thì với khách hàng.

== Description ==

ASFB Floating Buttons là plugin nhẹ giúp bạn kết nối tức thì với khách hàng qua các nút Gọi điện, Zalo, Facebook Messenger và Lên đầu trang. Phiên bản 2.2.0 được tối ưu cho WordPress 7.1+, không phụ thuộc jQuery, hỗ trợ chế độ thu gọn Speed Dial, nhãn gợi ý, ẩn trên trang Giỏ hàng/Thanh toán và đo lường sự kiện click.

TÍNH NĂNG CHÍNH:

* Đa kênh liên lạc: Gọi điện, Zalo, Facebook Messenger, Lên đầu trang.
* Không phụ thuộc jQuery: JavaScript thuần siêu nhẹ.
* Chế độ thu gọn (Speed Dial): Gom các nút vào 1 nút mở rộng gọn gàng trên mobile.
* Tùy chỉnh linh hoạt: Vị trí (trái/phải), kích thước nút (44/50/56px), khoảng cách lề, màu nền, nhãn gợi ý (tooltip) và xem trước trực tiếp trong trang cài đặt.
* Kiểm soát hiển thị: Chọn thiết bị (Desktop / Mobile / Tất cả) và tùy chọn ẩn trên trang Giỏ hàng / Thanh toán WooCommerce.
* Chuẩn SEO & Bảo mật: Tự động thêm rel="nofollow noopener noreferrer" cho liên kết ngoài.

== Installation ==

1. Tải thư mục hoặc file .zip của plugin vào `/wp-content/plugins/`.
2. Kích hoạt plugin trong trang Plugins của WordPress.
3. Đi tới Settings > ASFB Floating Buttons để cấu hình.
